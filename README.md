# 🦴 MY HAND BONE

**개발자와 디자이너의 손목을 뼈로 들여다보는 인터랙티브 3D 가이드**

맨체스터의 한 전시에서 축구선수의 발 뼈를 직접 만져 보며 "어디가 부러졌을까?"를 찾는 부스를 보고 영감을 받았습니다.
축구선수에게 발이 있다면, 개발자와 디자이너에게는 손과 손목이 있습니다.

👉 **https://progh2.github.io/myhandbone/**

## 기능

- **풀 3D 손 골격** — 27개 뼈(손목뼈 8 · 중수골 5 · 손가락뼈 14)와 요골·척골, 굽힘/폄 힘줄, 정중·척골신경, 가로손목인대, A1 도르래를 절차적으로 생성. 관절을 굽히면 힘줄과 신경이 함께 휘어집니다.
- **📷 내 손 미러** — 웹캠으로 손을 인식(MediaPipe Hand Landmarker)해 3D 뼈가 내 손과 똑같이 움직입니다. 관절 각도 표시, 힘줄 활주 운동 따라하기 채점, 선택형 손목 각도 측정(Pose Landmarker로 팔꿈치→손목 방향 추정). 영상은 브라우저 안에서만 처리됩니다.
- **작업 자세 비교** — 키보드, 마우스, 펜 태블릿, 스마트폰, 노트북 트랙패드, 중립 휴식 자세를 "흔한 자세 ↔ 권장 자세"로 애니메이션 비교
- **실시간 위험도 HUD** — 손목 각도·부하로 손목터널 압력(추정)과 6가지 통증 위험도를 계산하고 3D에서 해당 구조를 빨갛게 표시
- **직접 조작** — 슬라이더로 손목 굽힘/젖힘, 편위, 전완 회전, 쥐기를 바꿔 보며 압력 변화를 확인
- **통증·질환** — 손목터널증후군, 드퀘르뱅, 방아쇠수지, 척골신경 포착, 엄지 CMC, RSI의 증상·원인 작업·예방·진료 시점
- **스트레칭 & 자가체크** — 힘줄 활주, 손목 굽힘/폄근 스트레칭, 정중신경 활주, 엄지 맞서기, 팔렌·핀켈스타인 테스트를 3D로 따라하기 + 마이크로 브레이크 알림
- **TOUCH: 만져보기** — 내 손에서 직접 주상골, 두상골, 경상돌기 등을 찾아보는 가이드
- **골절 찾기 게임** — 금 간 뼈를 찾아 클릭 (주상골, 콜리스, 복서 골절, 유구골 갈고리, 베넷, 망치손가락)
- **내 책상 점검 & 손가락의 하루 계산기**

## 실행

빌드가 필요 없는 정적 사이트입니다 (Three.js · MediaPipe는 CDN). 카메라 기능은 HTTPS 또는 localhost에서만 동작합니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```
